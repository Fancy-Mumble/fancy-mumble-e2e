The headline from this round

Nebula's own text is translatable now

The first pass found 23 of Nebula's 94 .tsx files calling useTranslation, with the entire client shell hardcoded English. It is now 80 of 102, behind a Nebula-specific catalogue — eight namespaces, 537 keys, complete in English, German, French and Chinese, with the shared strings moved out to locales/common so the two packs no longer fight over one file.

Almost all of the remaining 22 files are layout primitives with no copy in them. Three do hold copy: Profile settings (41 strings), Voice settings (27) and the voice gate (3), plus one stray progress line in Personalize. That is the whole residue.

The channel-viewer control still does nothing

Partial

Settings search

Closed

Built differently on purpose, and the reasoning is worth keeping: Standard's panels self-register at module scope, which works because they are all statically imported. Nebula loads one page per chunk, so self-registration would only index pages you had already visited. The index is stated in one eagerly-loaded module instead, and pages publish their headings as data-settings-anchor so a result can flash the row it points at.
